Token Radar: a peer-calibrated implied-value board for unlaunched protocols. Implied value = TVL × the category peer multiple (median market-cap/TVL of listed same-category protocols in the snapshot, winsorized and shrunk by functional family) × 7-day growth × maturity × multi-chain breadth, after the house issuance screen (bridges, wrapped/staked products and exchange products are never ranked). Every ranked protocol carries a concrete 7-step farm plan. The static dashboard searches, filters and sorts the board and breaks down each valuation factor by factor. All numbers are derived from the snapshot at run time; nothing is hard-coded.

## Run it

```sh
node main.ts
```

The board, dashboard and dossier are written to the output directory.
